# Macのスワップが多いのに問題ない理由

## ① 何をしたかったか

MacBook Air M4 24GB のアクティビティモニタで、次の状態が気になった。

| 項目 | 値 |
|---|---|
| 物理メモリ | 24.00 GB |
| 使用済みメモリ | 9.36 GB |
| スワップ使用領域 | 10.09 GB |
| メモリプレッシャー | 緑 |

- 使用済みは少ないのに、なぜスワップが多いのか
- 緑なら本当に問題ないのか
- 発熱や負荷はどう見ればいいのか

## ② 何が起きたか / 気づいたこと

### 累計を見た

```bash
vm_stat | grep -E "Swapins|Swapouts"
```

| 項目 | ページ数 | 容量換算（×16KB） |
|---|---|---|
| Swapouts（SSDへ退避） | 2,278,741 | 約34.8 GB |
| Swapins（メモリへ戻す） | 1,372,567 | 約20.9 GB |

起動してからの累計なので、「今」起きているかは分からなかった。

### 「今」を見た

```bash
vm_stat 5    # 5秒ごとの増加量。1行目は累計なので無視。Control+C で停止
```

| swapins | swapouts |
|---|---|
| 713 | 0 |
| 16 | 0 |
| 20 | 0 |
| 168 | 0 |
| 12 | 0 |

swapouts が全て0。新たな退避は起きていなかった。

## ③ どう理解したか

### スワップは「過去の名残り」

macOS はメモリが足りない時にデータをSSDへ退避するが、メモリが空いても**わざわざ戻さない**。必要になった分だけ戻す。だから「今は空いているのにスワップだけ多い」状態になる。

> 例え：机（メモリ）に載りきらない書類を段ボール箱（スワップ）へ入れた。机が空いても、使わない書類は箱に入ったまま。

原因の候補：ブラウザのタブ（1タブ500MB〜1GB）＋ Codex ＋ LM Studio のモデル読み込み。

### 「今」の判定は swapouts を見る

| 5秒ごとの swapouts | 意味 |
|---|---|
| ほぼ0が続く | 健康。スワップは過去の名残り |
| たまに数十〜数百 | 軽い負荷。気にしなくてよい |
| 数千以上が出続ける | メモリ不足（スラッシング）。アプリやタブを閉じる |

swapins の少量は、古いタブに切り替えた時などに退避済みデータを戻しているだけ。

### スワップを減らす安全な方法は2つだけ

1. 重いアプリを `Command + Q` で完全終了（ウィンドウを閉じるだけではダメ）
2. 再起動（確実に0。累計もリセット）

```bash
sysctl vm.swapusage   # 現在のスワップ使用量
```

| やってはいけない / 効果がない | 理由 |
|---|---|
| `sudo purge` | キャッシュが消えるだけ。スワップは減らない |
| `/private/var/vm/` の swapfile 削除 | システムが不安定になる。絶対NG |
| スワップ無効化 | SIPで基本不可。できてもアプリが落ちるだけ |

### 発熱はスワップではなく CPU / GPU

- スワップは主にSSD寿命に関係し、発熱への影響は小さい
- MacBook Air はファンなし → 熱くなると自動で性能を落とす
- ローカルLLMは主に GPU を使う → CPUがアイドルでもGPUが全力のことがある
- GPU履歴：アクティビティモニタで `Command + 4`

```bash
pmset -g therm   # CPU_Speed_Limit = 100 なら制限なし
```

### チェック表

| 見たいこと | 見る場所 | 問題なしの目安 |
|---|---|---|
| メモリ不足か | メモリプレッシャー | 緑 |
| 今SSDに書き込んでいるか | `vm_stat 5` の swapouts | ほぼ0 |
| CPUの負荷 | CPUタブの「アイドル状態」 | 高い（例：80%以上） |
| GPUの負荷（LLM使用時） | `Command + 4` | 常に張り付いていない |
| 熱で性能が落ちているか | `pmset -g therm` | 100 |

## 教訓

- スワップの**量**ではなく、スワップの**増え方**（swapouts）を見る
- 普段は「プレッシャー緑」＋「CPUアイドル高」の2つで十分。LLM使用時だけGPUと熱を足す
- 累計の数字は単位（ページ＝16KB）をGBに換算してから考える
- 次は LM Studio でモデルを動かしながら `vm_stat 5` を観察し、Air と Mac mini の使い分けを決める
